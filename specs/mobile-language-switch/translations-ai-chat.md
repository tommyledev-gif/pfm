# Translations: Assistant tab (AI chat) and pending screen

> Scope: `app/(app)/(tabs)/ai-chat.tsx` (renders no copy of its own), `app/(app)/pending.tsx`, `src/features/ai-chat/**`. 240 rows covering all 237 extracted strings (JSX fragments merged into one key each) plus 3 the extractor missed (diacritic-free words, a template with no VI letters). Conventions: [translations.md](./translations.md).
>
> **Not in this file:** the assistant's replies themselves (transaction lead-ins, analysis answers, consult text, "ambiguous" replies) are generated by the backend and the AI service in Vietnamese. They are covered by [translations-errors.md](./translations-errors.md) (backend-rendered text). Only the copy the **app** writes into the thread is listed here.

## Notes for the whole area

1. **Client-written bubbles are persisted as text.** Several replies the app itself puts into the thread (`chat.reply.*`, `chat.image.reply.*`, `chat.consult.limitReached`, `chat.consult.pickCategory`, `chat.consult.error`, `common.empty.noWallet` from `reply-fanout.ts`) are stored in `chat-store` as a finished string. After a language switch, old bubbles would stay in the old language. refactor: store `textKey` + `textParams` on the message and render through `t()`; messages persisted before the change keep their stored text.
2. **Dates in the thread** go through `dayLabelVi` (`ChatDayLabel.tsx:32`, `ChatSearchResults.tsx:28`) and `toLocaleDateString("vi-VN")` / `toLocaleTimeString("vi-VN")` (`EditHistoryDialog.tsx:42`, `:44`). Both must take the active locale (see spec, formatting). The "Hôm nay" / "Hôm qua" words come from `common.date.today` / `common.date.yesterday`.
3. **Example chips and the caption placeholder are sent to the parser.** `chat.recording.examples.*` fill the input with text the AI service then parses, and the AI service is tuned for Vietnamese input. Switch these to English only once the extract service accepts English (spec open question).
4. **"Đề xuất" → "suggestion".** The UI calls an AI draft "đề xuất". The glossary has the status label ("Chờ xác nhận" → "Pending") but no noun; this file uses "suggestion" for the noun. Add it to `glossary.md` before shipping.
